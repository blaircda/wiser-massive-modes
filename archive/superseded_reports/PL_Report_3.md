### 2.1 The Algebraic Engine: Hanany–Forcella–Troost (HFT) Closed Form

$$r(q) \equiv Z_m(q) = \frac{Z_{\mathrm{Left}}(q) - Z_0}{q \, Z_Q}.$$

The chiral partition function $Z_{\mathrm{Left}}$ is expressed in closed form using plethystic exponentials of the virtual transverse vector $V_9 = [1,0,0,0]_9 - \mathbf{1}$:
$$Z_B = \operatorname{PE}\left[ \frac{q}{1-q}([1,0,0,0]_9 - 1) \right]$$
$$Z_F(q) = \operatorname{PE}_F\left[ \frac{q}{1-q}([1,0,0,0]_9 - 1) \right]$$
$$Z_{NS} = \frac{1}{2\sqrt{q}}\left( Z_F(\sqrt{q}) - Z_F(-\sqrt{q}) \right)$$
$$Z_{\mathrm{Left}} = \frac{1}{2}\left( [0,0,0,1]_8 - [0,0,1,0]_8 \right) + Z_B \left( Z_{NS} + \frac{1}{2}[0,0,0,1]_9 Z_F(q) \right)$$

$$R(q) = \frac{r(q)}{1-q} = \frac{Z_{\mathrm{Left}}(q) - Z_0}{q(1-q)Z_Q}.$$
